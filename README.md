hr-onboarding-sync
=====
Скрипт на Python, который фильтрует и переносит данные из таблицы по подбору сотрудников в таблицу, где отмечаются даты отправки сообщений новым кандидатам.

### Польза
Скрипт значительно сокращает время на ежедневную ручную фильтрацию, перенос и проверку данных, так как он не только добавляет новых кандидатов в отсортированном порядке, но и обновляет изменившиеся даты, а также удаляет отменившиеся приемы. Помимо этого, он создает новые листы на последующие месяцы приема, а также сохраняет информацию по отмеченным зеленым цветом ячейками, для контроля отправленных сообщений.

### Функционал скрипта
- фильтрация по заданным критериям
- добавление новых сотрудников
- обновление дат при изменениях в приеме
- удаление отменившихся приемов
- перенос между месяцами
- создание листов под каждый месяц (для внешних и внутренних кандидатов отдельные листы)
- учет ручных пометок (ячейки отмеченные зеленым цветом (C6E0B4))
- прошлые месяца не изменяются

### Стек
Python, pandas, openpyxl, putest
